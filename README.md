## 💻 Local Development

Run with any static local server or open directly in your browser:

```bash
# Clone the repository
git clone https://github.com/Arpit27-creator-tech/portfolio.git

# Enter project directory
cd portfolio

# Run a lightweight local server
python3 -m http.server 8080

# Or open in your browser
open index.html
```
